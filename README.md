
# ssss 🐍 - super special silverbullet setup

A collection of plugins/libraries for my personal Silverbullet configuration. (WIP)

> **Check out more of my plugins!** [Silverbullet Geonotes](https://github.com/garado/silverbullet-geonotes) adds interactive maps and location pins. 

## Features

### Sane table editor

Spreadsheet-like editor for tables.
- Edit cells in-place with support for Vim binds
- Click+drag to resize columns
- Menu for adding/deleting rows

### Theme switcher

Opinionated theming and a few nice colorschemes.

### Fancy frontmatter

Opinionated frontmatter rendering.

### Vim copies to system clipboard

Pressing <kbd>y</kbd> in Vim mode copies to system clipboard.
